Help & Docs

SpectraForge is a documentation and guidance workspace for laser materials — it stores your settings and lessons, it doesn't drive the machine. Here's how the pieces fit together.

THE WORKFLOW
Add a machine→Document a material→Calibrate→Save a recipe→Log attempts

Machines

Add each laser with its type (CO₂, Fiber, Diode, UV, IR-MOPA), wattage, bed size and add-ons. Set the min/max for every setting — these ranges constrain recipes and the calibration grid, and the parameter set adapts to the laser type (UV uses Q-Pulse and Interval instead of power %).

Materials

Document each stock with its thickness range, hazard level, safe power notes and an example photo. Materials link to the recipes proven against them, so you always know what worked.

Calibration Lab

Run a power × speed test grid bounded by the selected machine's real ranges. Click any cell to mark its result (clean / marginal / burnt), find the sweet spot, then promote it straight into a recipe.

Recipes & Attempts

A recipe is a saved set of settings for a material + machine. Every time you run one, log an attempt with input and result photos and an outcome. Enough clean attempts earn a recipe its calibrated badge.

SETTINGS GLOSSARY
PowerLaser output, usually a percentage of max wattage. Higher = deeper cut / darker mark.
SpeedHow fast the head or galvo moves (mm/s). Faster = less energy per area.
FrequencyPulses per second (kHz) on fiber/UV/IR lasers. Affects mark texture and contrast.
Q-Pulse / PulsePulse duration in nanoseconds (UV / IR-MOPA). Shorter pulses mark cooler with less heat spread.
IntervalLine spacing between galvo passes (mm). Smaller interval = finer fill, slower job.
DPI / ResolutionDots per inch on raster engraves. Higher = more detail, longer run-time.
PassesHow many times the job repeats. More passes deepen cuts without raising power.
